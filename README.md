## Why this exists
I was kinda bored and stumbled across hack club. I found out about something known as "hack craft lumen", and followed that guide, but apparently that project had already ended.  
I was able to submit it to a different hack club program, but in essence this shaderpack was mad for me to learn GLSL. this means it's not very good, nor is it very optimized (20 fps on an m4 Mac mini with 8 gigs of ram allocated to minecraft)

## features
- Stylized borders (adds some depth)
- fog (just fog)
- shadows (just shadows)
- Brighter caves than most shader packs (this is one of the things I hate the most about most shader packs. I don't want to choose between my game being beautiful and being able to see the ores)
- Water ripples
- Slightly upped vibrance
